1. Quick start

  1. Find the sound you want to add in section 3 (every file name) or the tables in sections 5–8. Each row gives the folder and the exact file name.
  2. Drop the file into that folder in the Unity Project window (or Explorer). Every audio path in this guide starts at Assets/_Project/Audio/Resources/. The folders already exist.
  3. Name it exactly as listed. Only the name matters; the extension doesn't (.wav, .mp3 or .ogg). Names are case-sensitive: Attack, not attack.
  4. Press Play. The game finds the file by name. Nothing to drag into the Inspector, no code to change.
  5. Commit the file and its .meta (section 11).

Example. To give Deadeye a rifle shot, save it as Assets/_Project/Audio/Resources/SFX/Operators/Sniper/Deadeye/Attack.wav. Every Deadeye shot now plays it. Add Attack_2.wav and Attack_3.wav and each shot picks one of the three at random.

4. Naming and file rules

RuleDetails
Exact namesUse the names in the tables exactly, with the same capitals and no spaces. ItemLandGlass, not Item Land Glass.
Any format.wav, .mp3 and .ogg all work. WAV is best for short effects; OGG or MP3 for music and long loops.
VariationsAdd _2, _3, … to any name (Attack_2, CarHit_2, Ability_Dodge_2). One is picked at random each time. The plain name counts as one of them and can be left out. Music doesn't use variations.
PitchUnit sounds get a small random pitch shift every time (±4%), so even one file doesn't sound robotic. Don't bake big pitch differences into variations.
Missing files are fineSounds marked fallback play an existing sound until their own file is added. Everything else is silent until a file exists. Nothing breaks.
Crowd controlThe same unit's sound won't restart within 0.08 s, and the same shared sound within 0.05 s. 40 rushers attacking or 5 burning operators won't stack into noise, so you don't need to make sounds quieter for that.
Enemy volumeEnemy sounds play at 70% (deaths at 80%) since many more enemies are on screen. Master them at the same loudness as operator sounds.
Attack stops on impactIf a unit has an Impact file, its still-running Attack sound is cut (a quick 0.04 s fade) the moment the impact plays, so a long launch or charge-up never overlaps its own explosion. Melee swings that hit instantly are left alone. Long attack sounds are fine.
Volume per fileSet in SfxVolumeSettings; see section 9.
LoopsMusic and the Ambience files loop. Make them seamless (no silence at the start or end). Ambience fades in and out automatically.
Unit folder namesThe unit's in-game name with spaces and symbols removed: "Chi Paw" → ChiPaw, "Stag-ger" → Stagger. If a unit is renamed, its folder must be renamed too.
Unit classOperators are grouped by their in-game class, not their asset name: Drawgoo lives in Defender/.

9. Unity import settings and volume

Unity imports audio with usable defaults, so this is optional. These settings keep memory low and avoid hitches. Select the file in the Project window and change them in the Inspector, then press Apply.

Kind of soundLoad TypeOther settings
Short effects (UI, attacks, hits, ticks)Decompress On LoadForce To Mono on. Compression Format: Vorbis or ADPCM.
Longer one-shots (Victory, Defeat, CarPass)Compressed In MemoryForce To Mono on unless the stereo matters. Vorbis.
Ambience loopsCompressed In MemoryKeep stereo. Vorbis.
MusicStreamingKeep stereo. Vorbis, quality around 70%.

Adjusting the volume of a file

Unity's audio import settings have no volume, so per-file volume lives in one settings asset: Assets/_Project/Audio/Resources/SfxVolumeSettings.

  1. Select SfxVolumeSettings in the Project window.
  2. In the Inspector, press + under Clips to add a row.
  3. Drag the audio file into Clip and set Volume (1 = as recorded, 0.5 = half).
  • Works for every sound effect: operators, enemies, UI and stage sounds. Not music or ambience.
  • Changes apply right away, even while the game runs in Play mode, and edits made in Play mode are kept.
  • Volume can only go down. To make a file louder than recorded, boost it in an audio editor.
  • Each variation (Attack, Attack_2, …) is its own row.

Recording and mastering tips

  • Trim silence from the start of every effect. Even 50 ms of lead-in makes a hit feel late.
  • Keep attacks short (under ~0.5 s). Fast operators attack about once a second, and the game is often played at 2× or 3× speed.
  • Bring all effects to a similar loudness and leave headroom (peaks around −1 dBFS). The game layers many sounds at once.
  • Variations should differ in character (a different swing, a different crunch), not just volume.

10. Testing your sounds

  1. Open the gameplay scene and press Play. Pick the stage that uses your sound; in the sandbox stage you can deploy cards mid-wave and the squad limit is lifted.
  2. Trigger the moment from the tables: deploy the operator, let it attack, retreat it, let an enemy die, and so on.
  3. If you hear the old sound or nothing, check section 12.
  4. Check volume against what's around it: at 3× speed with a full wave, your sound should still be readable but not dominate.

Files added while the game is running are picked up the next time you press Play.

11. Committing

  • Commit both the audio file and the .meta file Unity creates next to it. Without the .meta, teammates' copies of Unity give it a new ID.
  • Don't delete the .keep files in the folders; they keep empty folders in git.
  • Moving or renaming an existing file? Do it inside Unity (or move the .meta with it) so its ID is kept.
  • Keep source files (project files, uncompressed multitrack recordings) out of the repo; only the final exports go into Assets.

12. Troubleshooting

ProblemCheck
The sound never playsThe name is exact (capitals, no spaces, no extra suffix like Attack_final). The file is in the right folder under Resources. Unity imported it (it shows in the Project window with a waveform icon).
The old placeholder still playsThe sound has a fallback and your file isn't being found. Same checks as above.
Wrong unit folderThe folder must match the unit's in-game name with spaces and symbols removed, under its in-game class. Drawgoo is Defender/Drawgoo.
Only one of my variations ever playsVariations must be named Name_2, Name_3, … with a number after the underscore.
A loop clicks or has a gapTrim the start/end to zero crossings, or crossfade the loop point in your editor. Check for leading silence added by MP3 encoding; use OGG or WAV for loops.
A sound is too loud or quietLower it with a row in SfxVolumeSettings (section 9), or boost the file itself in an audio editor. The player's SFX slider and the 70% enemy level apply on top.
The sound plays at the wrong momentCheck the file name against the table: Attack is the swing or shot, Impact is the hit landing.

13. For programmers: adding a new sound trigger

Everything above works by dropping files. A new moment that should make a sound needs a few lines of code. Code lives in Scripts/Audio/AudioManager.cs (shared sounds) and Scripts/Audio/UnitSfx.cs (unit sounds).

A new shared sound (UI, gameplay, stage hazard)

  1. Add a value to the SfxId enum in AudioManager.cs.
  2. Add its file path to AudioManager.SfxPaths, e.g. { SfxId.Stage5Horn, "Stages/Stage05/Horn" }. Use an existing folder; never a loose file in SFX/.
  3. Play it where the moment happens:
AudioManager.Instance?.PlaySfx(SfxId.Stage5Horn);                 // silent until the file exists
AudioManager.Instance?.PlaySfxOrFallback(SfxId.Stage5Horn,        // plays the fallback until then
                                         SfxId.GameplayMeleeAttack);
AudioManager.Instance?.PlayAmbience(clip);                        // a custom loop (stage ambience is automatic)

A new operator ability sound

PlayAbilitySound();           // the operator's Ability file
PlayAbilitySound("Overdrive"); // Ability_Overdrive, falling back to Ability

Use a named ability only when the operator has more than one trigger.

Attacks and hits

  • Operators call PlayAttackSound() when an attack starts. It plays the operator's Attack file or the shared damage-type sound.
  • Hits go through enemy.TryTakeAttackDamage(damage, type, this). Passing this plays the operator's Impact automatically.
  • Enemies use PlayAttackSound() / PlayImpactSound() in EnemyBase.

Game-state sounds

Victory, defeat, wave cleared, card upgrade, deploy, retreat and deaths are raised from game events in AudioManager.SubscribeToGameplayEvents, not from UI code. Hook new game-state sounds there.

New units and stages

  • New operator or enemy: create its folder under SFX/Operators/{Class}/ or SFX/Enemies/{Archetype}/ with a .keep file. No code needed.
  • New stage: its music (Music/Stages/StageNN) and ambience (SFX/Stages/StageNN/Ambience) are found automatically. Hazard sounds go in SFX/Stages/StageNN/ with new SfxId values.

Keep the lists current. When you add a trigger, add its row to Assets/_Project/Audio/SFX_GUIDE.md and to this PDF (source: Docs/TRASH_TD_Audio_Guide.html), and note it in PROJECT_GUIDELINES.md §7.4.
